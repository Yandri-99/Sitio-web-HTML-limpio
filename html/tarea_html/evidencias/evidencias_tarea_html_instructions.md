Evidencias (PDF) - qué capturar y cómo

1) Capturas de las 5 páginas ejecutándose en el navegador
   - Abre cada archivo (`index.html`, `acerca.html`, `servicios.html`, `tabla.html`, `contacto.html`) en el navegador (arrastra el archivo o usa Live Server si lo prefieres).
   - Asegúrate que la barra de direcciones sea visible en la captura.

2) Árbol de carpetas
   - Captura el explorador de archivos mostrando la ruta `html/tarea_html/` con los 5 archivos.

3) Fragmentos de código
   - Captura (o copia) las secciones clave: el formulario en `contacto.html`, la tabla en `tabla.html`, y la nav común en cualquiera de las páginas.

4) Pull Request
   - Abre el PR desde la rama `tarea_html` hacia `main` en tu repositorio del curso.
   - Captura la pantalla donde se vea el PR abierto (título y lista de archivos cambiados).
   - Pega la URL del PR en el PDF.

5) Generar PDF
   - Usa una herramienta de tu elección (por ejemplo, Word/LibreOffice, PDF printer, o combine screenshots into one PDF).
   - Nombra el archivo: `evidencias_tarea_html.pdf` y súbelo al aula junto con la URL del PR.
