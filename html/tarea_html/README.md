# Tarea HTML - Sitio limpio (5 páginas)

Contenido:

- `index.html` - Página principal
- `acerca.html` - Información del proyecto
- `servicios.html` - Lista y ejemplo de código
- `tabla.html` - Tabla con caption, thead y tbody
- `contacto.html` - Formulario accesible con labels y distintos tipos

Instrucciones Git (en la raíz del repo):

1. Crear y moverse a la rama:
   git checkout -b tarea_html
2. Agregar y commitear:
   git add . ; git commit -m "Tarea HTML: sitio de 5 páginas sin CSS, formularios, tablas y nav"
3. Publicar la rama:
   git push -u origin tarea_html
4. Abrir Pull Request: tarea_html → main
